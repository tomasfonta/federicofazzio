Coloca aquí la foto que quieres mostrar en la cabecera.

Nombre recomendado: foto.jpg
Ruta en el repositorio: images/foto.jpg

Recomendaciones:
- Formato: .jpg o .png
- Tamaño sugerido: 600x600 px (la imagen se recorta en un círculo en la cabecera)
- Peso: menos de 300 KB para carga rápida en la web

Cómo añadir la foto localmente (macOS / zsh):

1) Guarda la imagen descargada desde el chat en tu equipo con el nombre "foto.jpg".
2) Mueve la imagen a la carpeta del proyecto:

   mv /ruta/donde/guardaste/foto.jpg images/foto.jpg

Si prefieres que yo agregue la imagen binaria al repositorio, sube el archivo aquí o dime cómo quieres proveerlo (por ejemplo, base64) y lo agrego por ti.
